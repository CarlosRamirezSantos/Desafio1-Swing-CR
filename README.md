🎷 Desafío 1: Swing Ciudad Real 📅 Descripción del proyecto

Con motivo del VII Festival de Swing de Ciudad Real, se propone desarrollar una aplicación web que permita registrar y gestionar las actividades y clases del próximo VIII Festival de Swing Ciudad Real (2026). El objetivo es crear una herramienta visual e interactiva que facilite la planificación del evento, mostrando un programa con todas las actividades y clases organizadas por día, hora y ubicación.

🎯 Objetivos

Permitir el registro de actividades y clases del festival. Generar automáticamente el programa del evento en una tabla visual. Garantizar que no se solapen actividades en las mismas salas o ubicaciones. Ofrecer una interfaz moderna, responsive y atractiva, coherente con la temática swing/jazz. Aplicar principios de desarrollo modular, POO y metodologías ágiles (SCRUM).

🧩 Tipos de actividades 🕺 Clases

Cada clase incluirá: Profesor/es Estilo (Lindy Hop, Shag, Solo Jazz…) Nivel (Básico, Intermedio, Avanzado…)

🎶 Actividades

Cada actividad podrá incluir: Tipo: Taster, Social, Concierto, Mix & Match Banda (si hay música en directo) Profesores/as implicados/as Estilo (Lindy Hop, Shag, Solo Jazz…) Descripción adicional

🏛️ Localizaciones y horarios

El festival se celebra del viernes a las 20:00h al domingo a las 20:00h. Salas de clases:

Be Hopper New Orleans Savoy (No pueden coincidir dos clases en la misma sala) Ubicaciones adicionales para actividades: Antiguo Casino de Ciudad Real Parque de Gasset Prado

Cualquiera de las salas anteriores (si están libres)

🖥️ Funcionalidades principales 🗓️ Registro de actividades

Formulario que solicita:

Día y hora Tipo de evento Ubicación disponible Validación automática de disponibilidad (no permitir solapamientos).

📋 Programa del festival

Visualización en formato tabla o cuadrícula según días y horas. Cada evento aparece como una tarjeta con su nombre y ubicación. Al hacer clic en una tarjeta, se muestra un modal con toda la información detallada. Se puede mover un evento mediante drag & drop (solo si la nueva franja horaria está libre).

🎨 Requisitos de diseño

Diseño de mockups y wireframes previos. Paleta de colores coherente con la temática swing y jazz. Diseño responsive, adaptable a móviles, tablets y ordenadores. Maquetación mediante HTML5 y CSS3 usando Grid y Flexbox. Experiencia de usuario (UX) cuidada: interfaz fluida, intuitiva y atractiva.

💻 Requisitos técnicos (Entorno Cliente)

Desarrollo basado en Programación Orientada a Objetos (POO). Uso correcto de funciones, eventos y estructuras de datos en JavaScript. Empleo de métodos de almacenamiento local (LocalStorage/SessionStorage). Proyecto estructurado en módulos ES6 con import/export. Validación de formularios y manejo de errores. Proyecto generado con Vite.

⚙️ Metodología de trabajo

Aplicación de principios Agile (SCRUM): Planificación de tareas por unidades funcionales completas. Desarrollo por sprints. Seguimiento mediante un repositorio en GitHub sincronizado con el profesor.

🧠 Tecnologías utilizadas

HTML5 / CSS3 (Grid, Flexbox) JavaScript (ES6+, módulos y POO) Vite (entorno de desarrollo) LocalStorage / SessionStorage Git / GitHub (control de versiones)

🚀 Próximos pasos

Implementar sistema de notificaciones o alertas de solapamiento. Posibilidad de exportar el programa a PDF o ICS (calendario). Integrar API externa para gestión de bandas o profesores.
